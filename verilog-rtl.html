⚙️ Activity 5 – RTL Modeling

Describe digital hardware using registers, combinational logic and clocked operations.

1. What is RTL Modeling?

RTL means Register Transfer Level. It describes how data moves between registers and what logic operates on that data.

RTL is widely used to describe synchronous digital systems such as counters, registers, ALUs and control logic.

💡 Think of RTL as: Register → Logic → Register

4. RTL Combinational + Sequential Thinking

An RTL design often contains both:

Combinational logic: calculates the next value.
Sequential logic: stores that value on a clock edge.
💡 The first block decides what the next state should be. The second block decides when the state is stored.

if (reset) should load 4'b0000.
