What is a Karnaugh Map?

A Karnaugh Map (K-Map) is a graphical method used to simplify Boolean expressions.

It helps us reduce the number of logic gates required to implement a digital circuit.

🔹 2-Variable K-Map

A 2-variable K-Map contains 4 cells representing all possible combinations of two variables A and B.

A \ BC 0 1
0 m0 m1
1 m2 m3

How to Simplify

  1. Write the Boolean function in minterm form.
  2. Place 1s in the corresponding K-Map cells.
  3. Group adjacent 1s.
  4. Find the simplified Boolean expression.

🟩 3-Variable K-Map Mapping

A 3-variable K-Map has 8 cells. The columns are arranged in Gray-code order: 00, 01, 11, 10.

A \ BC 00 01 11 10
0 m0 m1 m3 m2
1 m4 m5 m7 m6

🔹 Mapping: m0 → m1 → m3 → m2

🔹 Second row: m4 → m5 → m7 → m6

The adjacent cells differ by only one variable, which makes grouping possible in a K-Map.

🔹 3-Variable K-Map

A 3-variable K-Map contains 8 cells representing all possible combinations of variables A, B and C.

🟩 3-Variable K-Map Mapping

A 3-variable K-Map contains 8 cells for all possible combinations of A, B and C.

The columns are arranged in Gray-code order: 00, 01, 11, 10.

A \ BC 00 01 11 10
0 m0 m1 m3 m2
1 m4 m5 m7 m6

🔍 How the Mapping Works

Each cell represents one minterm of the three variables A, B and C.

The minterms are arranged as:

m0 → m1 → m3 → m2

m4 → m5 → m7 → m6

Adjacent cells differ in only one variable. This arrangement allows adjacent 1s to be grouped during Boolean simplification.

Example

Consider the Boolean function:

F(A,B,C) = Σm(1,3,5,7)

Place 1s in the cells corresponding to m1, m3, m5 and m7.

A \ BC 00 01 11 10
0 0 1
m1 		1
m3 		0
1 0 1
m5 		1
m7 		0

🟩 Group 1: m1 + m3 + m5 + m7

In this group, C = 1. Variables A and B change, so they are eliminated.

Therefore:

F = C

Example

Consider:

F(A,B,C) = Σm(1,3,5,7)

Place 1s in cells m1, m3, m5 and m7.

A \ BC 00 01 11 10
0 0 1 1 0
1 0 1 1 0

Group the four adjacent 1s.

In this group, the variable C remains constant at 1.

F = C

🔹 4-Variable K-Map

A 4-variable K-Map contains 16 cells representing all possible combinations of variables A, B, C and D.

🟦 4-Variable K-Map Mapping

The rows and columns are arranged in Gray-code order: 00, 01, 11, 10.

AB \ CD 00 01 11 10
00 m0 m1 m3 m2
01 m4 m5 m7 m6
11 m12 m13 m15 m14
10 m8 m9 m11 m10

🔍 How the Mapping Works

Each cell represents one minterm of the four variables A, B, C and D.

The K-Map follows Gray-code ordering:

00 → 01 → 11 → 10

Adjacent cells differ in only one variable. This arrangement makes it possible to group adjacent 1s and simplify Boolean expressions.

Example

Consider the Boolean function:

F(A,B,C,D) = Σm(0,1,2,3)

Place 1s in the cells corresponding to m0, m1, m2 and m3.

AB \ CD 00 01 11 10
00 1
m0 		1
m1 		1
m3 		1
m2
01 0 0 0 0
11 0 0 0 0
10 0 0 0 0

🟨 Group 1: m0 + m1 + m3 + m2

In this group, A = 0 and B = 0. Variables C and D change, so they are eliminated.

Therefore:

F = A'B'
