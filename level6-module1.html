Level 6: SystemVerilog, Module 1

SystemVerilog Fundamentals

SystemVerilog is Verilog with a bigger toolbox: clearer RTL, richer data types, and a full language for checking that your design works. This module teaches the data types every later module builds on, by letting you poke at them.

One wire, four possible values. Verilog and SystemVerilog both model all four, and knowing when a type can hold X or Z is the first skill you'll need.

Learning objectives

By the end of this module you will be able to:

  1. Explain what SystemVerilog adds to Verilog for design and for verification.
  2. Read the structure of a SystemVerilog design file, package and testbench.
  3. Choose between logic, bit, byte, int and integer, and predict their default values.
  4. Explain why a 2-state type can hide bugs that a 4-state type would show.
  5. Decide when a signal must be a net (wire) and when it can be a variable (logic).
  6. Decode sized, unsized and fill literals such as 8'hA5, 4'b10xz and '1.
  7. Tell packed from unpacked arrays and index them correctly.
  8. Use enum, struct, union and string to write clearer code.

Prerequisite: Level 3 (Verilog for Beginners). If always @(posedge clk) and assign look unfamiliar, revisit Level 3 first.

Verilog vs SystemVerilog

SystemVerilog (IEEE 1800) is a superset of Verilog: any legal Verilog-2001 file is also SystemVerilog. It adds features in two directions: safer design code, and a complete verification language.

2-state vs 4-state

A 4-state type (logic, reg, integer, wire) stores 0, 1, X and Z. A 2-state type (bit, byte, int) stores only 0 and 1. Click each state to learn what it means in real hardware.

wire vs logic: nets and variables

A net (wire) is a connection: it has no memory and takes the resolved value of everything driving it. A variable (logic, bit, int…) holds the last value written to it.

Net: wire

  • Driven by assign or a module output.
  • Can have many drivers (resolved, e.g. tri-state bus).
  • Can never be written inside always or initial.
  • Undriven value is Z.

Variable: logic

  • Written by procedural code or one assign.
  • Only one continuous driver allowed.
  • Keeps its value until written again.
  • Uninitialised value is X.

Legal or compile error? Activity

Practical rule: declare everything as logic. Switch to wire only when a signal really has more than one driver, such as a bidirectional or tri-state bus.

Literals and constants

A literal is written as <size>'<base><digits>. The size is in bits; the base is b, o, d or h. SystemVerilog adds fill literals '0, '1, 'x and 'z, which fill every bit of the target, whatever its width.

Constants

parameter  int WIDTH = 8;         // can be overridden when the module is instantiated
localparam int DEPTH = 1 << 4;    // fixed inside this module (16)
const      int MAX_PKTS = 100;    // run-time constant, mostly used in testbenches

Use parameter for things the user of your module should be able to change, and localparam for values derived from them.

Packed and unpacked arrays

Dimensions written before the name are packed: the bits are stored as one continuous vector and can be used as a single number. Dimensions written after the name are unpacked: a collection of separate elements, like a memory.

enum, struct, union and string

typedef gives a type a name you can reuse. These four features make code read like the problem it solves instead of raw bit vectors.

enum: named FSM states Activity

An enum lists the legal values of a variable by name. The simulator shows READ instead of 2'b01 in the waveform. Pick an encoding, then step through the states with the built-in methods.

struct: a packet with named fields Activity

A packed struct groups fields into one vector. The first field declared sits in the most significant bits. Change the fields and watch the 16-bit value.

typedef struct packed {
  logic [3:0] opcode;   // bits [15:12]
  logic [7:0] addr;     // bits [11:4]
  logic [3:0] data;     // bits [3:0]
} packet_t;

A packed union lets several members share the same storage. Here one 16-bit register can be read as a whole word or as two bytes. Edit either view.

A string grows and shrinks automatically and has built-in methods. It is for testbenches and messages, not synthesizable hardware. Indexes start at 0.

Practice questions

Work these on paper first, then open the model answer.

1. Why can using bit to sample a DUT output hide bugs?

A bit cannot store X or Z. If the DUT output is X (for example, an unreset register) or Z (an undriven output), it is silently converted to 0. The testbench then sees a clean 0 and may report a pass. Sample DUT outputs with logic so unknowns stay visible.

2. Declare an array for 32 words of 16 bits each. Which dimension is packed and which is unpacked? 
logic [15:0] mem [32];   // or: logic [15:0] mem [0:31];

[15:0] is packed: each word is a 16-bit number. [32] is unpacked: 32 separate words, like rows of a memory. mem[3] is one word; mem[3][15] is its MSB.

3. Write a packed struct for a header with an 8-bit dest, an 8-bit src and a 16-bit len. What is its width, and which bits hold src? 
typedef struct packed {
  logic [7:0]  dest;   // [31:24]
  logic [7:0]  src;    // [23:16]
  logic [15:0] len;    // [15:0]
} hdr_t;

The struct is 32 bits wide. The first field is the most significant, so src occupies bits [23:16].

4. When must you use wire instead of logic?

When a signal has more than one driver that must be resolved, such as a tri-state bus driven by several assign ... ? ... : 'z statements, or an inout port. A logic variable allows only one continuous driver.

5. Write an enum for a 4-state FSM (IDLE, LOAD, SHIFT, DONE) with one-hot encoding. What does DONE.next() return? 
typedef enum logic [3:0] {
  IDLE  = 4'b0001,
  LOAD  = 4'b0010,
  SHIFT = 4'b0100,
  DONE  = 4'b1000
} state_t;

next() moves to the next value in the declaration order and wraps around, so after DONE it returns IDLE.

6. What are the values of these after logic [7:0] a = 8'b1z; and logic [7:0] b = 8'bz1;?

a = 0000_001z: the leftmost given digit is 1, so the value is padded with 0s. b = zzzz_zzz1: the leftmost given digit is z, so the padding is z.
