💻 Introduction to Verilog

Learn the basic concepts of Verilog HDL through simple examples.

What is Verilog?

Verilog is a Hardware Description Language (HDL) used to describe and model digital electronic systems.

It allows us to describe the behaviour and structure of digital circuits using code.

1️⃣ Basic Verilog Module

A Verilog design is usually written inside a module. 

module circuit_name(
    input A,
    input B,
    output Y
);

    // Circuit description

endmodule

2️⃣ Understanding the Module

Keyword Meaning
module Starts a Verilog module
input Defines an input signal
output Defines an output signal
assign Used for continuous assignment
endmodule Ends the module

3️⃣ Your First Verilog Program

module and_gate(
    input A,
    input B,
    output Y
);

assign Y = A & B;

endmodule

🔍 Understand the Code

A and B are the inputs of the AND gate.

Y is the output.

The statement

assign Y = A & B;

performs the AND operation.

4️⃣ Basic Verilog Operators

Operator Operation Example
& AND A & B
| OR A | B
~ NOT ~A
^ XOR A ^ B
~^ XNOR A ~^ B
