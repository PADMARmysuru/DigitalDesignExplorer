🎯 Verilog & Digital Circuits Interview Questions

100 important questions for interview preparation

Showing 100 Questions
Question 1

What is Verilog HDL?

Verilog is a hardware description language used to model, design, simulate, and verify digital electronic systems.
Question 2

What is the difference between Verilog and C?

Verilog describes hardware behavior and structure, while C primarily describes software algorithms executed on a processor.
Question 3

What is a Verilog module?

A module is the basic design unit in Verilog. It defines ports, internal signals, and the logic that implements a hardware block.
Question 4

What are input, output, and inout ports?

Input ports receive signals, output ports drive signals, and inout ports can both receive and drive signals.
Question 5

What is a wire?

A wire represents a net used to connect hardware elements and is driven by a source.
Question 6

What is a reg?

A reg is a procedural variable that can be assigned inside procedural blocks such as always or initial.
Question 7

Difference between wire and reg?

A wire is a net driven by a source, while a reg is a procedural variable.
Question 8

What is continuous assignment?

A continuous assignment uses assign to drive a net whenever the right-hand expression changes.
Question 9

What is an always block?

An always block describes procedural behavior that executes when its triggering event occurs.
Question 10

What is an initial block?

An initial block starts at simulation time zero and executes once, commonly in testbenches.
Question 11

Blocking vs non-blocking assignment?

Blocking (=) updates immediately in procedural order; non-blocking (<=) schedules an update and is commonly used for sequential logic.
Question 12

Which assignment is preferred for flip-flops?

Non-blocking assignment (<=) is generally used for clocked sequential logic.
Question 13

Which assignment is preferred for combinational procedural logic?

Blocking assignment (=) is commonly used.
Question 14

What does always @(*) mean?

It creates a combinational procedural block sensitive to signals read by the block.
Question 15

What is a sensitivity list?

It specifies the events or signals that cause an always block to execute.
Question 16

What are posedge and negedge?

posedge detects 0-to-1 transitions; negedge detects 1-to-0 transitions.
Question 17

How is a D flip-flop described?

Use an always block triggered by posedge clk with a non-blocking assignment such as q <= d.
Question 18

What is a clocked always block?

It is an always block triggered by a clock edge and used for sequential logic.
Question 19

What is reset?

Reset initializes sequential elements to known states and may be synchronous or asynchronous.
Question 20

Synchronous vs asynchronous reset?

A synchronous reset acts on the active clock edge; an asynchronous reset can act independently of the clock.
Question 21

What is a latch?

A latch is a level-sensitive storage element.
Question 22

How can unintended latch inference be avoided?

Assign outputs for every possible condition using complete if/else or case logic.
Question 23

What is a case statement?

It selects one branch based on the value of an expression.
Question 24

Difference between case, casex, and casez?

case uses exact matching; casex treats x and z as don't-care values; casez treats z and ? as don't-care values.
Question 25

What is a default case?

It handles values not matched by explicit case items.
Question 26

What is a parameter?

A parameter is a constant that can be overridden during module instantiation.
Question 27

What is a generate statement?

Generate constructs create repeated or conditional hardware structures during elaboration.
Question 28

What is a testbench?

A testbench is a simulation environment used to apply inputs and verify outputs.
Question 29

What is DUT?

DUT means Design Under Test.
Question 30

What is a simulator?

A simulator executes a hardware description according to HDL simulation semantics.
Question 31

What is synthesis?

Synthesis converts synthesizable HDL into a hardware implementation representation.
Question 32

What is synthesizable Verilog?

It is Verilog code that synthesis tools can translate into implementable hardware.
Question 33

Give examples of simulation-only constructs.

Delays, many initial-block stimulus constructs, and system tasks such as $display are commonly simulation-oriented.
Question 34

What does #10 mean?

It specifies a simulation delay of 10 time units.
Question 35

What is `timescale?

It specifies simulation time unit and time precision.
Question 36

What is a vector?

A vector is a multi-bit signal such as [7:0].
Question 37

Scalar vs vector?

A scalar is one bit; a vector contains multiple bits.
Question 38

How are signals concatenated?

Use braces, for example {a,b,c}.
Question 39

What is replication?

Replication repeats a value or vector a specified number of times.
Question 40

What is the ternary operator?

The ?: operator selects one of two expressions based on a condition.
Question 41

How can a multiplexer be modeled?

Using a conditional operator, if/else, or case statement.
Question 42

How can a decoder be modeled?

Using combinational logic, case statements, or Boolean expressions.
Question 43

What is an FSM?

A finite state machine is a sequential model consisting of states and transitions.
Question 44

Mealy vs Moore FSM?

Mealy outputs depend on state and input; Moore outputs depend only on state.
Question 45

What is a race condition?

It occurs when simulation results depend on the order of simultaneous procedural updates.
Question 46

Why use non-blocking assignments in sequential logic?

They model simultaneous register updates and reduce ordering-related simulation problems.
Question 47

What is a multiple-driver problem?

It occurs when unintended multiple sources drive the same signal.
Question 48

What is a test vector?

A test vector is a set of inputs applied during verification.
Question 49

What is RTL?

RTL stands for Register Transfer Level and describes data transfers between registers and intervening logic.
Question 50

What is the purpose of assertions?

Assertions specify expected properties and can automatically detect violations during verification.
Question 51

What is a digital circuit?

A digital circuit processes discrete signal levels, commonly represented as binary 0 and 1.
Question 52

What are the basic logic gates?

AND, OR, and NOT are basic gates; NAND, NOR, XOR, and XNOR are also widely used.
Question 53

What is a universal gate?

A universal gate can implement any Boolean function. NAND and NOR are universal gates.
Question 54

Why is NAND universal?

NOT, AND, and OR can all be constructed using only NAND gates.
Question 55

Why is NOR universal?

NOT, OR, and AND can all be constructed using only NOR gates.
Question 56

What is XOR?

XOR produces 1 when its inputs are different.
Question 57

What is XNOR?

XNOR produces 1 when its inputs are equal.
Question 58

What is Boolean algebra?

It is a mathematical system used to represent and simplify logical relationships.
Question 59

State De Morgan's theorems.

The complement of a product equals the sum of complements, and the complement of a sum equals the product of complements.
Question 60

What is a minterm?

A minterm is a product term containing every variable exactly once.
Question 61

What is a maxterm?

A maxterm is a sum term containing every variable exactly once.
Question 62

What is a K-Map?

A Karnaugh map is a graphical method for simplifying Boolean expressions.
Question 63

Why use Gray-code ordering in K-Maps?

Adjacent cells then differ in only one variable.
Question 64

What group sizes are allowed in a K-Map?

Groups contain powers of two cells such as 1, 2, 4, 8, and 16.
Question 65

Can K-Map groups wrap around edges?

Yes. Opposite edges are considered adjacent.
Question 66

What is Quine–McCluskey method?

It is a tabular systematic method for minimizing Boolean functions.
Question 67

What is a don't-care condition?

It is an input combination whose output is unimportant and may be used to simplify logic.
Question 68

What is a half adder?

It adds two one-bit binary numbers and produces Sum and Carry.
Question 69

Which gates are used in a half adder?

XOR for Sum and AND for Carry.
Question 70

What is a full adder?

It adds two data bits and a carry-in and produces Sum and Carry-out.
Question 71

How is a full adder constructed from half adders?

Two half adders and an OR gate can form a full adder.
Question 72

What is a ripple-carry adder?

It is an adder where carry propagates from one stage to the next.
Question 73

What is carry propagation delay?

It is the delay associated with carry traveling through successive adder stages.
Question 74

What is a multiplexer?

A multiplexer selects one of several inputs and connects it to one output.
Question 75

What is a demultiplexer?

A demultiplexer routes one input to one of several outputs.
Question 76

What is an encoder?

An encoder converts an active input into a binary code.
Question 77

What is a priority encoder?

It outputs the code of the highest-priority active input.
Question 78

What is a decoder?

A decoder converts an n-bit input into up to 2^n output lines.
Question 79

What is a comparator?

It determines whether one binary number is greater than, less than, or equal to another.
Question 80

What is a latch?

A latch is a level-sensitive storage element.
Question 81

What is a flip-flop?

A flip-flop is an edge-triggered storage element that stores one bit.
Question 82

Latch vs flip-flop?

A latch responds to a level; a flip-flop normally responds to a clock edge.
Question 83

What is an SR flip-flop?

It has Set and Reset controls and stores one bit.
Question 84

What is a D flip-flop?

It transfers the D input to its output on the active clock edge.
Question 85

What is a JK flip-flop?

It provides hold, set, reset, and toggle behavior based on J and K.
Question 86

What is a T flip-flop?

It toggles when T is active and holds when T is inactive.
Question 87

What is a register?

A register is a group of flip-flops used to store a multi-bit value.
Question 88

What is a shift register?

It stores data and shifts it left or right with clock pulses.
Question 89

What is a counter?

A counter is a sequential circuit that progresses through a sequence of states.
Question 90

Synchronous vs asynchronous counter?

Synchronous counters use a common clock; asynchronous counters ripple the clock from stage to stage.
Question 91

What is propagation delay?

It is the time between an input change and the corresponding output change.
Question 92

What is setup time?

It is the minimum time data must be stable before the active clock edge.
Question 93

What is hold time?

It is the minimum time data must remain stable after the active clock edge.
Question 94

What is metastability?

It is an uncertain temporary state that can occur when timing requirements are violated.
Question 95

What is a synchronous circuit?

It uses a clock to coordinate state changes.
Question 96

What is a combinational circuit?

Its outputs depend only on current inputs.
Question 97

What is a sequential circuit?

Its outputs depend on current inputs and stored previous state.
Question 98

What is an FSM?

A finite state machine is a sequential model with a finite set of states and transitions.
Question 99

What is fan-in?

Fan-in is the number of inputs a logic gate accepts.
Question 100

What is fan-out?

Fan-out is the number of standard logic inputs one output can reliably drive.
