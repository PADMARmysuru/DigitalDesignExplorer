📐 Activity 3 – Data-Flow Modeling

Describe what the output should be using expressions and continuous assignments.

1. What is Data-Flow Modeling?

Data-flow modeling describes how data moves from inputs to outputs.

We mainly use the assign statement and Boolean operators.

Think: Input → Expression → Output

💡 Unlike structural modeling, we do not draw each gate. We write the logic expression directly.

2. The Most Important Statement: assign

Read it as: “Continuously make y equal to a AND b.”
