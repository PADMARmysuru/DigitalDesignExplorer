3.1 Introduction to CMOS

CMOS stands for Complementary Metal-Oxide-Semiconductor. Every CMOS gate uses two networks of transistors that work as opposites:

PMOS network (pull-up) connects the output to VDD.
NMOS network (pull-down) connects the output to GND.
For any input, one network conducts and the other is OFF.

Why PMOS pulls up and NMOS pulls down

PMOS is ON when the gate is 0.
It passes a full logic 1 (VDD) but a weak 0, so it is used only between VDD and the output.

NMOS is ON when the gate is 1.
It passes a full logic 0 but a weak 1 (about VDD − VTH), so it is used only between the output and GND.

3.2 CMOS Inverter

The inverter (NOT gate) is the simplest CMOS gate: one PMOS above the output and one NMOS below it, both driven by the same input A.
