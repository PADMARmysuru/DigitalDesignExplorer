Quine–McCluskey Method

A systematic tabular method for minimizing Boolean functions

📚 What is it?

The Quine–McCluskey method is a systematic procedure used to minimize Boolean functions using minterms.

🔢 Main Idea

Minterms are converted into binary form and repeatedly combined to eliminate variables.

🎯 Goal

Find the minimum Boolean expression using prime implicants and essential prime implicants.

💡 Why Use Quine–McCluskey?

  • Provides a systematic Boolean minimization procedure.
  • Useful for functions with several minterms.
  • Can be implemented using a computer program.
  • Produces prime implicants and essential prime implicants.
  • Provides a tabular alternative to Karnaugh maps.

📖 Steps of the Method

  1. List all minterms.
  2. Convert minterms to binary.
  3. Group minterms according to the number of 1s.
  4. Compare adjacent groups.
  5. Combine terms that differ in exactly one bit.
  6. Repeat the combination process.
  7. Identify prime implicants.
  8. Create the prime implicant chart.
  9. Select essential prime implicants.
  10. Write the minimized Boolean expression.

📝 Step-by-Step Worked Example

Let us minimize the following Boolean function using the Quine–McCluskey method.

F(A,B,C,D) = Σm(0,1,2,3,8,9,10,11)

Convert Minterms to Binary

STEP 3

STEP 4

First Combination

Compare terms from adjacent groups. Terms that differ in exactly one bit can be combined. The differing bit is replaced by –.

Minterms Combination
0,1 000-
0,2 00-0
0,8 -000
1,3 00-1
1,9 -001

STEP 5

Second Combination

The combinations from the previous step are compared again. Terms differing in one remaining position can be combined.

Minterms Combined Pattern
0,1,2,3 00--
0,1,8,9 -00-
0,2,8,10 -0-0
1,3,9,11 -0-1
2,3,10,11 -01-
8,9,10,11 10--
STEP 6

Final Combination

The combinations can be compared further. The common pattern that covers all the required minterms is:

Minterms Covered Pattern Meaning
0,1,2,3,8,9,10,11 -0-- B = 0

The pattern -0-- means:

  • A can be either 0 or 1 → A is eliminated
  • B is always 0 → B′ remains
  • C can be either 0 or 1 → C is eliminated
  • D can be either 0 or 1 → D is eliminated
STEP 7

Prime Implicant

Prime Implicant Boolean Expression Minterms Covered
-0-- B′ 0,1,2,3,8,9,10,11
STEP 8

Prime Implicant Chart

Prime Implicant 0 1 2 3 8 9 10 11
B′ ✓ ✓ ✓ ✓ ✓ ✓ ✓ ✓
STEP 9

Essential Prime Implicant

The prime implicant B′ covers all the minterms in the function. Therefore, it is the essential prime implicant.

Essential Prime Implicant = B′
STEP 10

Final Simplified Expression

F(A,B,C,D) = B′

🎉 Therefore, the minimized Boolean function is B′.
