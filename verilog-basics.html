Understand the idea first, then write your first Verilog program.

1. What is Verilog?

Verilog is a Hardware Description Language (HDL).
It is used to describe the behavior and structure of digital circuits.

In this course, you will use Verilog to describe circuits such as logic gates, adders, multiplexers, flip-flops and counters.

💡 Think of Verilog as a way to write the design of a digital circuit using code.

2. Where Verilog Fits in the VLSI Design Flow

Verilog is mainly used when the digital design is described at the RTL / HDL level.

3. Verilog Basics

Before programming, remember these simple ideas:

Term Simple meaning
module A block that represents a digital circuit.
input A signal entering the circuit.
output A signal leaving the circuit.
assign Used for a continuous assignment in data-flow style.
endmodule Marks the end of the module.

4. Your First Verilog Program – AND Gate

Code What it means
module and_gate Creates a module named and_gate.
input a First input signal.
input b Second input signal.
output y Output signal.
assign y = a & b; The output follows the AND operation.
endmodule Ends the module.
💡 Circuit idea: y = a AND b. The output is 1 only when both inputs are 1.
