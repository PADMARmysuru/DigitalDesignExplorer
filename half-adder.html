🔧 Half Adder

Learn how two binary numbers can be added using a Half Adder.

What is a Half Adder?

A Half Adder is a combinational circuit used to add two single-bit binary numbers.

It produces two outputs:

  • SUM
  • CARRY

💻 Verilog Implementation

module half_adder(
    input A,
    input B,
    output SUM,
    output CARRY
);

assign SUM = A ^ B;
assign CARRY = A & B;

endmodule
